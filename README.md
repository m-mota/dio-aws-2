# 🚀 Desafio Prático - AWS Step Functions

## 📌 Descrição do Projeto

Este repositório foi criado como parte de um laboratório prático com o objetivo de consolidar o aprendizado sobre **workflows automatizados utilizando AWS Step Functions**.

Durante a realização do desafio, foram explorados conceitos fundamentais de orquestração de serviços na AWS, permitindo entender como criar fluxos de trabalho escaláveis, resilientes e baseados em eventos.

O principal objetivo deste projeto é servir como **material de apoio para estudos futuros**, reunindo anotações, insights e aprendizados adquiridos ao longo das aulas.

---

## 🎯 Objetivos de Aprendizagem

Ao concluir este desafio, foi possível:

- Aplicar conceitos teóricos em um ambiente prático utilizando AWS Step Functions;
- Compreender a importância da orquestração de workflows em arquiteturas serverless;
- Documentar processos técnicos de forma clara e organizada;
- Utilizar o GitHub como ferramenta de versionamento e compartilhamento de documentação técnica;
- Desenvolver uma visão mais prática sobre automação de processos na nuvem AWS.

---

## 🧠 Conceitos Estudados

Durante o laboratório, foram abordados os seguintes conceitos:

- AWS Step Functions e State Machines
- Integração com serviços AWS (Lambda, SNS, SQS, etc.)
- Fluxos de trabalho baseados em estados
- Tratamento de erros e retries em workflows
- Execução assíncrona e escalabilidade
- Monitoramento e rastreabilidade de execuções
